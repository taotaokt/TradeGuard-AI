# Security policy

TradeGuard AI is a portfolio project and should be evaluated only with public-safe or fictional data.

Do not open a public issue containing credentials, personal data, confidential company records, financial statements, invoices, or vulnerability details. Report a security concern privately to the repository owner.

Before any real organizational use, replace development credentials, use managed secrets and TLS, restrict network access, encrypt backups, scan uploads, configure retention and deletion, add rate limiting and monitoring, and commission an independent security review. The included synthetic model is not approved for real credit decisions.
