# TradeGuard AI - 中文项目简介

TradeGuard AI 是一个面向中小型进出口企业的、可解释的交易风险决策工作台。我开发这个项目，是为了把通常分散在表格和聊天记录中的流程连接起来：交易对手建档、证明文件、受限方筛查、付款与交易条件、确定性规则、统计风险估计、人工复核和审计记录。

系统采用 FastAPI、SQLAlchemy 和 Alembic，支持角色权限、SQLite/PostgreSQL、响应式网页界面和 PDF 报告。机器学习部分使用固定随机种子生成不包含真实企业信息的合成数据，对比经过概率校准的逻辑回归与随机森林，并根据留出测试集的校准和区分能力选择 champion。推理时会验证模型文件哈希；如果输入超出训练范围，系统会降低置信度并转人工复核。投资组合分析不会直接混合不同币种，并会保存可复现、不会改变实际决策的压力测试快照。

项目最重要的产品设计是区分不同类型的决策权：模型只能辅助商业信用风险判断，不能消除或覆盖合规 hard stop。每次评估都会保存输入快照、名单版本、规则校验值、模型版本、预测特征、原因码、系统建议和人工决定。

这个项目用于展示全栈工程、应用机器学习、模型治理、产品思维、自动化测试和风险沟通能力。它不是生产级授信系统，也不声称合成数据上的表现可以直接迁移到真实信用决策。
